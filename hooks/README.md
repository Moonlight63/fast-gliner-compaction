# fast-gliner-compaction Claude Code mod

`hooks/fast-gliner.ts` is a thin adapter around the library in `src/`.

- It reads the plugin options. Comma-separated `removeTools` and `keepTools`
  become glob lists. When the options leave `serverUrl` and `serverToken`
  unset, it fills them from `FGC_SERVER_URL` and `FGC_TOKEN` (process
  environment first, then settings.json `env`).
- It sends `session.compact` transcripts to the library, using `$.http.fetch`
  for the decision server, and maps the result back onto session messages.
  Untouched messages keep their engine handles. Rebuilt messages and trace
  lines are fresh copies.
- A failing decision server does not stop compaction. The rules still apply,
  calls they cannot place are trimmed, and the toast names the error. The hook
  delegates to the built-in compaction only on an unexpected error, or when
  the reduction is below `minReductionRatio`.
- `turn.complete` requests compaction once `context.percent` reaches
  `compactAtPercent`, with an in-flight guard.

The outcome is shown as a toast and logged:

- The summary line gives the reduction, the removed / trimmed / kept counts,
  and how many calls were decided by rule versus by the model.
- A `decisions:` line gives each call's action and reason, for example
  `t3:Bash:remove/superseded` or `t9:Bash:trim/model_trim=0.12`.

Function hooks are early access. The type reference in `types/claude-code.d.ts`
was generated by Claude Code 2.1.287; regenerate and review it after
upgrading. See the root README for setup and options.
