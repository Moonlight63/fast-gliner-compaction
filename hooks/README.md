# fast-gliner-compaction Claude Code mod

`hooks/fast-gliner.ts` is a thin adapter around the library in `src/`.

- It reads the plugin options. Comma-separated `cheapTools` and
  `expensiveTools` become glob lists. When the options leave `serverUrl` and
  `serverToken` unset, it fills them from `FGC_SERVER_URL` and `FGC_TOKEN`
  (process environment first, then settings.json `env`).
- It sends `session.compact` transcripts to the library, using `$.http.fetch`
  for the decision server, and maps the result back onto session messages.
  Untouched messages keep their engine handles; rebuilt ones are fresh copies.
- A failing decision server does not stop compaction. The rules still apply,
  calls the rules leave unknown keep their output, and the toast names the
  error. The hook delegates to the built-in compaction only on an unexpected
  error, or when the reduction is below `minReductionRatio`.
- `turn.complete` requests compaction once `context.percent` reaches
  `compactAtPercent`, with an in-flight guard.

The outcome is shown as a toast and logged:

- the summary line holds the reduction, the counts, and how many calls were
  decided by rule versus by the model;
- a `decisions:` line holds, for each call, the action, the reason
  (`cheap`, `expensive`, `model_spared`, `model_dropped`, or
  `model_unavailable`) and the model's P(expensive) when it was asked.

Function hooks are early access. The type reference in `types/claude-code.d.ts`
was generated by Claude Code 2.1.274; regenerate and review it after
upgrading. See the root README for setup and options.
