# fast-gliner-compaction Claude Code mod

`hooks/fast-gliner.ts` is a thin adapter around the library in `src/`.

- It reads the plugin options and fills `serverUrl` and `serverToken` from
  `FGC_SERVER_URL` and `FGC_TOKEN` (process environment, then settings.json
  `env`) when the options leave them unset.
- It sends `session.compact` transcripts to the decision server through
  `$.http.fetch` and maps the result back onto session messages. Untouched
  messages keep their engine handles; rebuilt ones are fresh copies.
- When the server is unreachable, returns an error, or answers malformed, or
  when the reduction is below `minReductionRatio`, it logs the reason and
  delegates to the built-in compaction.
- `turn.complete` requests compaction once `context.percent` reaches
  `compactAtPercent`, with an in-flight guard.

The outcome is shown as a toast and logged with the reduction, per-reason
counts, outline size, request count and model time. A `decisions:` line logs
both probabilities for every call.

Function hooks are early access. The type reference in `types/claude-code.d.ts`
was generated by Claude Code 2.1.274; regenerate and review it after upgrading.
See the root README for setup and options.
